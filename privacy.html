Goodware Privacy Policy

Goodware is a Windows desktop business application.

Google Account Access

Goodware uses Google OAuth authorization to allow users to send email from their own Google account directly from the Goodware application.

Goodware requests permission to send email on behalf of the authenticated user. This access is used only when the user initiates an email from within Goodware.

Google User Data

Goodware does not use Google authorization to read, modify, or delete the user's Gmail messages.

Google authentication credentials are used only for the purpose of providing the email-sending functionality requested by the user.

Data Protection

Goodware protects Google user authorization data by storing OAuth credentials locally within the individual user's Windows profile. The credentials are not stored in Goodware's business database and are not transmitted to or stored on a Goodware-operated server.

Access to the locally stored authorization data is limited by the security controls of the user's Windows account. Goodware uses the OAuth credentials only to authenticate directly with Google's Gmail API over HTTPS for the purpose of sending email requested by the user.

Goodware does not use Google authorization to retrieve or store the contents of the user's Gmail mailbox. Access is limited to the gmail.send scope required for Goodware's outgoing email functionality.

OAuth credentials are used only to authenticate requests made directly to Google's Gmail API for the purpose of sending email requested by the user.

Data Retention and Deletion

Google OAuth authorization credentials are retained locally on the user's computer so that the user does not need to authorize Goodware each time the application is used.

The user may remove this locally stored authorization data at any time. The user may also revoke Goodware's access to their Google account through their Google Account security settings. After the locally stored authorization data is removed or access is revoked, Goodware must be authorized again before it can send email through that Google account.

Data Sharing

Goodware does not sell Google user data or share Google user data with third parties for advertising or marketing purposes.
